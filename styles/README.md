# styles/ — sistema visual por camada

```
foundation/  → tokens, base, design-system, desktop-responsive
layout/      → navegação / estrutura
components/  → componentes reutilizáveis (botões base, modais…)
modules/     → CSS por área de produto (agenda, KPIs, IA…)
themes/      → dark, impressão/acessibilidade
```

Ordem de carga definida em `index.html` (cascata preservada).
